    Como jogar
    
        
    Escreva seu programa em G-Portugol e aperte Ctrl+Enter (ou Analisar).
           Cada erro encontrado vira um esqueleto no corredor lá embaixo. Corrija o código e analise de novo:
           o cavaleiro derrota os esqueletos dos erros que sumiram. Sem nenhum erro, o portão se abre.
    
        
    Aperte Esc para sair do editor e controle o cavaleiro com ← →,
           ↑ (pular) e X (atacar). Encoste num esqueleto, passe o mouse ou clique nele para ver o erro.
    

        
    O que o analisador verifica
    
        
      
          
    1. Tabela de símbolos: cada variável, parâmetro e função com seu tipo e escopo (o Grimório).
      2. 
          
    2. Variável ou função não declarada.
      3. 
          
    3. Declaração duplicada no mesmo escopo.
      4. 
          
    4. Compatibilidade de tipos: atribuições, operadores, condições de se/enquanto,
              índices de matriz, argumentos e retornos de função. Um inteiro pode ir para um real; o contrário não.
      5. 
          
    5. Resultados linha a linha, no console.
      6. 
        
    

        
    Cola de G-Portugol
    

    algoritmo exemplo;

variáveis
    x, y: inteiro;
    nome: literal;
    notas: matriz[5] de reais;
fim-variáveis

início
    x := leia();
    se x > 0 e x <> 10 então
        imprima("positivo");
    senão
        imprima("outro");
    fim-se
    para y de 0 até 4 faça
        notas[y] := dobro(y);
    fim-para
fim

função dobro(n: inteiro) : real
início
    retorne n * 2;
fim
